# MeshInspector x Zeno Founder Deck

Open `index.html` in a browser and present full screen.

`MeshInspector-Zeno-Founder-Deck.pdf` is a shareable 10-page PDF export generated from the same slides.

Controls:

- `Right Arrow`, `Space`, or click right side: next slide
- `Left Arrow` or click left side: previous slide
- `N` or the `Notes` button: toggle speaker notes
- `Home` / `End`: first / last slide
- Browser print can export a PDF, one slide per page

Recommended demo flow during the call:

1. Present slides 1-4 to frame the manufacturing gap.
2. Switch to the live MeshInspector app for one short model walkthrough.
3. Return to slides 8-10 for packaging, pilot, and the ask.
